# Фирменный стиль Quattro Formaggi

Дизайн-система v1.0 (30.09.2026): знак `> qf_`, цвета, шрифты, правила применения.

| Что | Где |
|---|---|
| Регламент (цвета, типографика, сетка, голос, контроль перед публикацией) | `DESIGN_SYSTEM_RU.md` |
| Токены | `tokens.css`, `tokens.json` |
| Проверка контраста (WCAG) | `CONTRAST_CHECK.md` |
| Логотипы: тёмный и светлый фон, прозрачные, иконки | `logos/` (SVG — мастер, PNG — готовые) |
| Баннеры: карточки Hugging Face (en, ru), превью GitHub 1280×640 | `banners/` |

Шрифты DejaVu Sans и DejaVu Sans Mono (свободная лицензия, русские буквы поддерживаются) в репозиторий не включены; шаблоны публикаций, пресс-тексты и исходный рендер хранятся вне Git (`research/publication/brand/`). Баннеры собраны из токенов и логотипа этого каталога. Правила: не менять интервалы и курсор знака, не добавлять тень и свечение, цифры в публикациях — только вместе с названием метрики и знаменателем; перед публикацией сверять числа с `docs/EVAL_SPEC.md`.
